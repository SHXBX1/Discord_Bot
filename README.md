# MeowPailong Bot

## ติดตั้ง
1. ต้องใช้ **Node.js 22.12 ขึ้นไป** (ไลบรารีเสียงบังคับ)
2. `npm install`
3. คัดลอก `.env.example` เป็น `.env` แล้วกรอก `DISCORD_TOKEN`, `CLIENT_ID`, `GUILD_ID` (GUILD_ID = เซิร์ฟบ้านเรา)
4. Discord Developer Portal → Bot → เปิด **Server Members Intent** (ไม่งั้นบอทไม่ออนไลน์: error "disallowed intents")
5. `npm run deploy` ลงทะเบียนคำสั่งแบบ global (ใช้ได้ทุกเซิร์ฟ) | ทดสอบเร็วๆ ใช้ `npm run deploy:guild`
6. `npm start`

เชิญบอทด้วยสิทธิ์: Manage Roles, Manage Channels, Move Members, Manage Events, Create Events, Send Messages, Send Polls, Embed Links, Connect, Speak + scope `bot` และ `applications.commands`

## /setup
**เซิร์ฟบ้านเรา (GUILD_ID):** ไปช่องที่ต้องการแล้วพิมพ์ `/setup panel` ครั้งเดียว บอทสร้างฉายาที่ยังไม่มีให้เอง
แล้วส่งแผงตามค่าใน `config.js` (แก้ชื่อ/สี/อีโมจิในไฟล์นั้นได้) ห้อง Create Room, ฉายาเลเวล ฯลฯ ใช้ค่าจาก config.js ด้วย

**เซิร์ฟอื่น:** ตั้งทีละขั้น
1. สร้างฉายาใน Server Settings → Roles
2. `/setup group add` สร้างหมวด → `/setup role add` ใส่ฉายาเข้าหมวด (ทำซ้ำ)
3. ลากฉายาบอทให้อยู่เหนือฉายาที่จะแจก
4. `/setup panel` ในช่องที่ต้องการ

เสริม: `/setup hub` (ห้องสร้างห้องส่วนตัว) • `/setup memberrole` • `/setup birthdayrole` • `/setup levelrole add` • `/setup timezone` • `/setup banner` • `/setup show` (ดูสถานะ) • `/setup reset` • `/log set` (ช่องแจ้งเตือน)

ฉายาที่มีสิทธิ์สูง (Administrator, Manage Roles, Ban ฯลฯ) บอทไม่ยอมให้ใส่ในแผง/แจกให้คนกดเอง

## ระบบเพลง
เล่นเพลงเข้าห้องเสียงด้วย yt-dlp → ffmpeg → `@discordjs/voice` ควบคุมด้วยคำสั่งหรือปุ่มบนการ์ด Now Playing
รองรับชื่อเพลง (ค้นหา YouTube) และลิงก์ YouTube / SoundCloud / Bandcamp รวมเพลย์ลิสต์ (สูงสุด 50 เพลงต่อครั้ง) ยังไม่รองรับ Spotify | คิวเก็บได้สูงสุด 200 เพลง

| `/setconsole` | ตั้งห้องนี้เป็นห้องคอนโซลเพลง การ์ดค้างไว้ถาวร ใส่ `remove:true` เพื่อยกเลิก (ต้องมีสิทธิ์ Manage Server) |
| `/pause` `/resume` `/skip` | หยุดชั่วคราว / เล่นต่อ / ข้ามเพลง |
| `/stop` `/leave` | ล้างคิวแล้วให้บอทออกจากห้อง (ถ้าเปิด 24/7 อยู่ จะปิด 24/7 ให้ด้วย) |
| `/queue` `/clearqueue` `/remove` | ดูคิว / ล้างคิว (เพลงที่เล่นอยู่เล่นต่อ) / เอาเพลงออกทีละเพลง (ไม่ใส่ลำดับ = เลือกจากเมนู) |
| `/nowplaying` `/loop` `/shuffle` `/volume` | ดูเพลงปัจจุบัน / วนเพลง (ปิด, เพลงเดียว, ทั้งคิว) / สับคิว / ปรับเสียง 0-100 |
| `/favorite add\|list\|play` | เพลงโปรดของแต่ละคน (เก็บได้ 100 เพลง) เพิ่ม / ดู-เล่น-ลบ / เล่นทั้งหมด (สุ่มลำดับได้) |

### การ์ด Now Playing
- หน้าตาเป็นเทปคาสเซ็ต: ม้วนซ้ายค่อยๆ เล็กลง ม้วนขวาใหญ่ขึ้นตามความคืบหน้าของเพลง แกนกลางหมุน (`+` / `x`) ทุกครั้งที่การ์ดอัปเดต (ทุก 10 วินาที) ขึ้น `■` ตอนหยุดชั่วคราว และมีแถบเวลา, ระดับเสียง, โหมดวน, จำนวนเพลงในคิว
- เมนูแนวเพลงอยู่บนการ์ด เปลี่ยนแนวได้ทันที
- **Quick Actions** (ปุ่มที่มีไอคอนแสดงแค่ไอคอน):
  - แถว 1: ⏸/▷ หยุด-เล่นต่อ • ⏭ ข้าม • ✚ เพิ่มเพลง • 🔎︎ ค้นหา • ☰ คิว
  - แถว 2: ❤︎ เพลงโปรด • ⌛︎ ประวัติ • ၊၊||၊ ปรับเสียง • ↺ Reset
  - แถว 3: `Auto: On/Off` • `Controls`
- **✚ เพิ่มเพลง**: 1 บรรทัด = 1 เพลง/ลิงก์ ใส่ได้สูงสุด 10 บรรทัดต่อครั้ง
- **↺ Reset**: ล้างคิวทั้งหมดและปิดโหมดเล่นตามแนว เพื่อให้เปิดเพลงเองได้เต็มที่ (เพลงที่กำลังเล่นยังเล่นต่อจนจบ)
- **Controls**: แผงควบคุมเต็ม (ก่อนหน้า, ข้าม, หยุด, ล้างคิว, สับ, วน, ปรับเสียง, mute, ออกจากห้อง, ลบเพลงทีละเพลง) เห็นคนเดียว

### แนวเพลง / Autoplay
- **เล่นตามแนว**: เลือกแนวจากเมนู บอทจะหาเพลงมาเติมคิวให้เรื่อยๆ ไม่ต้องสั่งอะไรเพิ่ม (เพลงที่ยาวเกิน 10 นาทีหรือสั้นกว่า 1 นาทีจะถูกข้าม) แนวที่มี: เพลงไทยฮิต, ไทยอินดี้, ไทยอีสาน, ไทยร็อก, ไทยเพื่อชีวิต, Lofi, Phonk, Conscious Hip Hop, Modern Trap, EDM, Pop, Rock, K-Pop แก้/เพิ่มได้ในรายการ `GENRES` ใน `modules/music.js` (key ห้ามซ้ำ สูงสุด 24 แนว)
- **Autoplay**: เมื่อคิวหมด บอทหาเพลงที่คล้ายกับเพลงล่าสุดมาเล่นต่อ (ค่านี้จำไว้ต่อเซิร์ฟ)
- พอเปิดเพลงเองแล้วอยากให้ระบบเลิกเติมคิว: กด **↺ Reset** หรือปิด Auto / เลือก "ปิดโหมดเล่นตามแนว" ซึ่งสองอย่างหลังจะ **ล้างคิวให้อัตโนมัติ** (เพลงที่เล่นอยู่เล่นต่อ)

### โหมด 24/7 (`/247`)
ให้บอทประจำห้องเสียงห้องเดียวและเล่นเพลงต่อเนื่องตลอดทั้งวัน ต้องมีสิทธิ์ Manage Server
- `/247` สลับเปิด/ปิด หรือระบุ `mode`, `channel` (ห้องเสียงที่ให้ประจำ ไม่เลือก = ห้องที่คุณอยู่) และ `genre` (แนวที่จะเล่นเรื่อยๆ ไม่เลือก = สุ่มแนวเมื่อคิวหมด)
- บอทไม่ออกจากห้องเอง แม้คิวหมดหรือไม่มีใครอยู่ในห้อง เมื่อคิวหมดจะเล่นตามแนวที่ตั้งไว้ → Autoplay (ถ้าเปิด) → สุ่มแนว
- ถ้าหลุดหรือโดนเตะจะเข้าห้องใหม่ให้เอง และเปิดบอทใหม่แล้วจะกลับเข้าห้องเดิมเล่นต่อเอง (ค่าเก็บใน `data/db.json`) ถ้าห้องถูกลบ โหมดจะปิดเอง
- ถ้าเล่นไม่ได้ติดกัน 5 เพลง (เช่น YouTube บล็อก) บอทจะพักแล้วลองใหม่เอง
- `/stop` และ `/leave` (รวมปุ่ม Stop/Leave) จะปิด 24/7 ด้วย เพื่อไม่ให้บอทเข้ามาใหม่
- มีผลต่อเซิร์ฟละห้องเดียว ระหว่างเปิดอยู่ คนอื่นสั่ง `/play` จากห้องอื่นไม่ได้ ต้องปิด `/247` ก่อน
- ขึ้นป้าย `SIDE A · 24/7` บนการ์ด Now Playing
- โหมดปกติ (ไม่เปิด 24/7): คิวหมดแล้วบอทอยู่ต่อ 3 นาทีก่อนออก และออกถ้าไม่มีคนอยู่ในห้อง 1 นาที

### ติดตั้งสิ่งที่ต้องใช้
ต้องติดตั้งบนเครื่องที่รันบอท:
- **yt-dlp** (https://github.com/yt-dlp/yt-dlp/releases) ให้อยู่ใน PATH หรือตั้ง `YTDLP_PATH` ใน .env — อัปเดตบ่อยๆ ด้วย `yt-dlp -U` เพราะ YouTube เปลี่ยนบ่อย
- **JS runtime สำหรับ YouTube**: ติดตั้ง **Deno** (yt-dlp ใช้อัตโนมัติ) หรือถ้ามี Node 22+ อยู่แล้วตั้ง `YTDLP_JS_RUNTIME=node`
- ffmpeg มากับ `npm install` แล้ว (ffmpeg-static)
- เสียงกระตุกบนเครื่องที่ CPU ไม่แรง: ลอง `npm install @discordjs/opus` (ตัวเข้ารหัสเสียงแบบ native เบากว่า `opusscript` ที่ติดมาให้) แต่ยังไม่ได้ทดสอบว่าช่วยได้แค่ไหน

ตัวแปรใน `.env` ของระบบเพลง: `YTDLP_PATH`, `YTDLP_JS_RUNTIME`, `YTDLP_COOKIES`, `YTDLP_COOKIES_FROM_BROWSER`

ถ้าเจอ "Sign in to confirm you're not a bot" (มักเกิดบน VPS/โฮสต์) บอทจะลองใช้ client ทางเลือกของ YouTube ให้เองก่อน ถ้ายังไม่ผ่านให้ export cookies ของบัญชี YouTube เป็น `cookies.txt` แล้วตั้ง `YTDLP_COOKIES=cookies.txt` (ใช้บัญชีสำรอง ไม่ใช่บัญชีหลัก) หรือถ้าบอทรันบนเครื่องเดียวกับเบราว์เซอร์ที่ล็อกอิน YouTube อยู่ ตั้ง `YTDLP_COOKIES_FROM_BROWSER=firefox` แทนได้

ข้อมูลของระบบเพลง (คอนโซล, เพลงโปรด, ประวัติ, ค่า Auto, ค่า 24/7) เก็บใน `data/db.json` ร่วมกับข้อมูลอื่นของบอท

| `/valorant matches` | รายการแข่ง Esports ที่กำลังแข่ง/กำลังจะแข่ง เวลาแสดงตามเขตเวลาของแต่ละคน |
| `/valorant weapon` | ข้อมูลปืน: ราคา อัตรายิง รีโหลด ดาเมจหัว/ตัว/ขาตามระยะ (ไม่ใส่ชื่อ = รายการทั้งหมด) |

ต้องมี **API key ฟรี** จาก HenrikDev (ยกเว้น `weapon`): เข้าดิสคอร์ด HenrikDev → ช่อง #get-a-key → เลือก "VALORANT (Basic Key)"
แล้วใส่ `HENRIK_API_KEY=...` ใน `.env` (ดู `.env.example`) จากนั้น `npm run deploy` ใหม่ (มีคำสั่งใหม่)

ข้อควรรู้: Riot ไม่เปิด API สถิติผู้เล่นให้ใช้ทั่วไป ข้อมูลจึงมาจากบริการของชุมชน (HenrikDev, valorant-api.com) ที่ไม่ใช่ของ Riot
โควต้าของ key นับรวมทั้งบอท บอทจึงแคชผลไว้ 3-15 นาทีและกันกดรัว (8 วินาที/คน) | ถ้าบอทอยู่หลายเซิร์ฟและคนใช้เยอะ ให้ขอ key ระดับ Advanced

## โครงสร้าง
`config.js` ค่าเริ่มต้นเซิร์ฟบ้านเรา • `settings.js` ค่าตั้งแต่ละเซิร์ฟ • `db.js` เก็บข้อมูลที่ `data/db.json` (สำรองด้วยการคัดลอกไฟล์)
`modules/` แต่ละระบบ — อยากปิดระบบไหน ลบบรรทัดใน `modules/index.js` แล้ว `npm run deploy` ใหม่
